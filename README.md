# Java Quiz Application

A desktop-based **Quiz Application developed using Java Swing and AWT**. Users can enter their name, attempt Java multiple-choice questions, use a help/lifeline option, and view their final score.

## Features

- User name entry
- Java-based multiple-choice questions
- 15-second timer for each question
- Help/Lifeline option
- Next and Submit buttons
- Automatic score calculation
- Final score display
- Restart quiz option

## Technologies Used

- Java
- Java Swing
- Java AWT
- Event Handling
- OOP Concepts

## Application Flow

Login → Rules → Quiz → Score

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA or Eclipse.
3. Run `Login.java`.
4. Enter your name and start the quiz.
